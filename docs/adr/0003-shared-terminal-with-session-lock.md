# 共享终端：AI 与用户共用一个 Shell

AI 的命令直接写入用户当前 Session 的 PTY，由 Session Lock 保证互斥：AI 执行期间键盘输入默认不写入 PTY、按 Esc 中止；当输出命中密码/确认提示（sudo、`Password:`、`yes/no`）时临时把输入权交还用户，用户在终端内直接输入、回车后收回，终端常驻"接管输入"按钮兜底误判；检测到全屏程序或未结束命令时 AI 拒绝执行而不是发 Ctrl-C。用户手动命令通过会话内注入的 shell 钩子采集（bash/zsh，OSC 633 风格上报退出码、cwd、命令文本，不写入目标机磁盘），其他 shell 降级为仅审计 AI 命令。**Why**：共享 shell 状态让 AI 的 `cd`/`export` 天然延续用户上下文，也免去第二条 shell 的生命周期管理。**后果**：AI 命令必须用随机标记包裹以确定边界；钩子失效时 UI 要明示"用户命令审计不可用"。
