# 只读运维 Runbook

Runbook 以应用内置模板的形式提供常见排障流程。第一版包含主机健康检查、服务故障排查和日志快速分析，模板可以填写服务名或日志路径等少量参数，并展示即将使用的步骤。

选择 Runbook 后只生成一条聊天草稿，不直接调用终端。用户可以检查或修改草稿，再选择自动执行、逐条确认或仅解释策略发送给 AI。AI 仍然一次执行一个命令，所有命令经过 deny-list、超时、共享 PTY、审批和审计链路。

Runbook 步骤限定为只读检查；不适用的命令必须记录并跳过，不能用替代命令掩盖失败。模板暂不支持用户自定义、持久化、条件分支或写操作，避免在没有版本管理和审批模型前引入不可见的批量变更。

**Why**：重复排障需要稳定的检查顺序和完成标准。模板能减少用户临时组织提示词的成本，同时把执行边界和预期结果显式展示出来。

**后果**：模板覆盖范围有限，复杂环境仍需要用户调整草稿；Runbook 的结果仍是 AI 对话和命令审计记录，不额外创建一套执行历史。
