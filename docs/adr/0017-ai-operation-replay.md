# AI 操作过程与结果回看

每条 AI 命令的完成事件同时携带命令、状态、退出码、耗时和捕获输出。聊天时间线把这些字段保存到 `chat_message` 的命令 payload，因此刷新页面或重新连接后仍能恢复完整步骤卡片。

前端命令卡片提供：

- 复制命令和复制输出；
- 折叠查看输出，避免长输出占满对话区；
- 对非零退出码、超时、取消和不可用结果提供“重试此步骤”，重试会以新的 AI 回合提交，继续使用当前 Session 和当前执行策略。

输出沿用 PTY 捕获层的头尾保留与截断规则，审计日志仍使用自己的 4 KiB 输出上限。待确认命令不写入历史，只有批准后的执行结果或拒绝结果进入时间线。

**Why**：用户需要知道 AI 实际执行了哪些步骤、拿到了什么结果，并能从失败步骤继续处理。把结果放在聊天事件和 SQLite transcript 中，可以同时覆盖实时查看和重启后回看。

**后果**：重试是一次新的 AI 回合，模型可能根据当前 Session 状态调整命令；它不会盲目复用旧命令的退出上下文。审计记录仍以 `audit.jsonl` 为准，当前 UI 还没有审计文件筛选器。
